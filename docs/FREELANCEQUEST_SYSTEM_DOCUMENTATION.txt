1. PRODUCT OVERVIEW & CORE PHILOSOPHY
--------------------------------================--------------------------------
FREELANCEQUEST is a complete web-based gamified learning platform that teaches
people how to become successful Virtual Assistants (VAs) and freelancers while
making the learning experience feel like an entertaining RPG video game.

The system takes a complete beginner from "I don't know how freelancing works"
to "I have skills, an ATS resume, a live portfolio, proposals, interview practice,
clients, income, and a sustainable freelancing career."

Simultaneous System Functions:
 1. Learning Management System (LMS)
 2. RPG Career Simulator
 3. Skills-Training Platform
 4. Job-Application Simulator
 5. Public Portfolio Builder (`/p/username`)
 6. ATS Resume & CV Builder (`/resume-builder`)
 7. Cover Letter Generator (`/cover-letter-builder` with KISS method)
 8. AI Interview Simulator Arena
 9. B2B Client Sourcing & Lead Generation Engine
10. Freelance Business & Agency Simulator
11. Professional Community Platform (`/community`)
12. Resource Vault (`/resources` with 32 downloadable SOPs & templates)
13. Verifiable Certification System (`/verify/FQ-XXXX-1234`)
14. Monetizable SaaS Platform (Free, Pro $19/mo, Master $49/mo)
15. Admin CMS & Database Control Center (`/admin`)

--------------------------------================--------------------------------
2. TECHNOLOGY STACK & ARCHITECTURE
--------------------------------================--------------------------------
- Backend Engine: Pure Native PHP 8.3 (Framework-Free Architecture)
- Architecture Pattern: Custom Front-Controller MVC with Regex Router
- Database Engine: SQLite (`database/database.sqlite`) via PDO Prepared Statements
- Frontend Styling: HTML5, Tailwind CSS, FontAwesome Icons, Vanilla JavaScript
- Security Safeguards: CSRF Tokens, Rate Limiting, CSP Headers, Session Renewal, XSS Escaping

3. DATABASE SCHEMA & ARCHITECTURE (31 TABLES)
--------------------------------================--------------------------------
1. `users` — Learner profiles, roles (student, admin), level, XP, coins, streak_count, subscription_tier.
2. `levels` — 16 RPG career levels (0 to 15), required XP, certificates, icons.
3. `skill_categories` — Technical, Business & Sales, Professional Skills.
4. `skills` — Specific skills linked to categories.
5. `user_skills` — Learner proficiency and mastery ratings.
6. `courses` — 16 Course Modules mapped to Levels 0–15.
7. `lessons` — 96 Masterclass Lessons (6 per level) with rich HTML content.
8. `lesson_progress` — User completion records and completion timestamps.
9. `quizzes` — 96 Knowledge Check Quizzes linked to lessons.
10. `questions` — 288 Multiple Choice Questions (3 per quiz) with option arrays and explanations.
11. `quiz_attempts` — User quiz scores and improvement tracking.
12. `missions` — 50 Interactive Scenario Missions (calendar, inbox, lead gen, social media).
13. `mission_attempts` — User scenario submissions and score evaluations.
14. `daily_quests` — Generated daily missions for XP/coin bonuses.
15. `badges` — 20 Achievement Badges with XP bonuses.
16. `user_badges` — Awarded badges per user.
17. `certificates` — Issued level completion certificates with unique verification codes.
18. `resources` — 32 Downloadable Vault Resources mapped across Levels 0–15.
19. `resumes` — ATS Resume Builder entries (contact info, skills, experience, education).
20. `portfolios` — Public portfolio websites with custom slugs, tagline, about, and services.
21. `portfolio_items` — Case studies, work samples, and screenshots.
22. `groups` — Community discussion groups.
23. `community_posts` — Forum posts, questions, and success stories.
24. `comments` — User comments on community posts.
25. `subscriptions` — Active user subscription records (Free, Pro, Master).
26. `payments` — Transaction logs (PayPal, Stripe, GCash) and reference numbers.
27. `settings` — System settings (pricing, XP multipliers, payment gateways, page content).
28. `coupons` — Discount coupons (percentage or fixed dollar discounts).
29. `testimonials` — User reviews submitted for homepage moderation.
30. `audit_logs` — System audit logs for admin activity tracking.
31. `jobs` / `job_applications` / `applications_tracker` — Job board postings and pipeline tracker.

8. DEPLOYMENT & LOCAL SETUP INSTRUCTIONS
--------------------------------================--------------------------------
Localhost Setup (XAMPP / PHP CLI):
1. Navigate to project root directory.
2. Initialize database schema and seeds: `php database/seed.php`
3. Start development server: `php -S localhost:8000 -t public`
4. Access platform in browser: `http://localhost:8000`

cPanel / Web Server Deployment:
1. Upload project files to web server root directory (`public_html`).
2. Set document root to point to the `public/` directory.
3. Ensure write permissions on `database/database.sqlite`.
