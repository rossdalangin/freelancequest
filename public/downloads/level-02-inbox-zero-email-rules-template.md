### 2. CORE OPERATIONAL FRAMEWORK & TEMPLATE BLUEPRINT
### INBOX ZERO AUTOMATION & LABELING FRAMEWORK

#### 1. The 4-Category Label System
Create the following parent labels in client Gmail accounts:
- `01_ACTION_REQUIRED`: High-priority emails needing client decisions today.
- `02_WAITING_REPLY`: Emails sent where we are waiting on external response.
- `03_READ_LATER`: Newsletters, industry reports, non-urgent updates.
- `04_FINANCE_RECEIPTS`: Invoices, receipts, software subscriptions.

#### 2. Automated Gmail Filter Rules Matrix
```text
Filter Rule 1:
IF 'Has the words': "Invoice" OR "Receipt" OR "Order Confirmation"
THEN: Apply Label '04_FINANCE_RECEIPTS' + Skip Inbox (Archive)

Filter Rule 2:
IF 'From': newsletters@* OR contains "Unsubscribe"
THEN: Apply Label '03_READ_LATER' + Skip Inbox
```
