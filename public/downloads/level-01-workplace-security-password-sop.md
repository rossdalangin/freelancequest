### 2. CORE OPERATIONAL FRAMEWORK & TEMPLATE BLUEPRINT
### STANDARD OPERATING PROCEDURE: PASSWORD SECURITY & ACCESS CONTROL

#### 1. Security Baseline Configuration Rules
- **Rule 1: Zero Plaintext Passwords.** Passwords must NEVER be sent via Slack, Email, WhatsApp, or Google Sheets.
- **Rule 2: Password Manager Requirement.** Use Bitwarden or 1Password for all account credential storage.
- **Rule 3: Master Password Strength.** Master passwords must be 16+ characters combining letters, numbers, and symbols.
- **Rule 4: Mandatory 2FA.** Enable Two-Factor Authentication (2FA) using Google Authenticator or YubiKey on all client accounts.

#### 2. Secure Access Request Checklist
- [ ] Install Bitwarden extension on dedicated client browser profile.
- [ ] Provide client with your Bitwarden email address for secure credential sharing.
- [ ] Verify permissions received (Read-only vs Full Access).
- [ ] Confirm 2FA backup code protocol with client in case of device loss.
