# Client Onboarding SOP Checklist

## Pre-Kickoff
- [ ] Sign Freelance Service Agreement / Contract
- [ ] Confirm Payment Retainer Terms
- [ ] Collect Client Credentials via Password Manager (LastPass/1Password)

## Kickoff Call & Operations
- [ ] Confirm Primary Communication Channel (Slack/Teams)
- [ ] Verify Calendar Access & Sharing Permissions
- [ ] Set Daily EOD Update Schedule
