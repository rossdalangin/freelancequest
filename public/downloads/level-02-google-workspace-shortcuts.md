# Google Workspace Keyboard Shortcuts Cheat Sheet

## Gmail Shortcuts
- `c`: Compose new email
- `e`: Archive email thread
- `r`: Reply
- `a`: Reply all
- `/`: Search inbox

## Google Drive & Sheets Shortcuts
- `Ctrl + Shift + F`: Freeze header row
- `Ctrl + Alt + M`: Add comment
- `=VLOOKUP(search_key, range, index, [is_sorted])`: Data lookup
