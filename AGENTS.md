# Instructions for Autonomous Agents

This codebase is a pure native PHP 8.3 application using PDO SQLite and a lightweight custom MVC router.

## Principles
- **No Frameworks:** Do NOT introduce Laravel or other heavy web frameworks.
- **Testing:** Run tests using `./vendor/bin/phpunit tests/NativeFreelanceQuestTest.php`.
- **Database:** SQLite database located at `database/database.sqlite`. Run `php database/seed.php` to initialize.
