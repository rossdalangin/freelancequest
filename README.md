# FREELANCEQUEST — Pure Native PHP Platform

FREELANCEQUEST is a gamified Virtual Assistant & freelancing career simulator built purely with native PHP 8.3, PDO SQLite, and responsive Tailwind CSS views without any external web frameworks.

## Quick Start

### 1. Initialize Database & Seed Content
```bash
php database/seed.php
```

### 2. Run Local Web Server
```bash
php -S localhost:8000 -t public
```

### 3. Run Test Suite
```bash
./vendor/bin/phpunit tests/NativeFreelanceQuestTest.php
```
